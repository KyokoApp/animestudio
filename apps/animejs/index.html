Intuitive API

Animate faster with an easy-to-use, yet powerful animation API.

animate('.square', {
  rotate: 90,
  loop: true,
  ease: 'inOutExpo',
});

Enhanced transforms

Smoothly blend individual CSS transform properties with a versatile composition API.

animate('.shape', {
  x: random(-80, 80),
  y: random(-60, 60),
  rotate: random(-180, 180),
  composition: 'blend',
});

Advanced staggering

Create stunning effects in seconds with the built-in Stagger utility function. Hover or click dots below.

createTimeline()
  .add('.dot', {
    scale: stagger([1.2, 0.6], { from: 'center' }),
    ease: 'inOutQuad',
  }, stagger(50));

Springs and draggable

Drag, snap, flick and throw HTML elements with the fully-featured Draggable API.

createDraggable('.circle', {
  releaseEase: createSpring({
    stiffness: 120,
    damping: 6,
  })
});

Runs like clockwork

Orchestrate animation sequences and keep callbacks in sync with the powerful Timeline API.

createTimeline()
  .add('.ticker', {
    rotate: 360,
    duration: 2000,
    loop: true,
  });
