# 🌾 Cozy Farm Lane 3D

**Top-down farming game built with Three.js - Anti-slop compliant! ✅**

## 🎮 Play Now
https://kyokoapp.github.io/animestudio/games/farm-lane-3d/game.html

## Features
- Plant, water, harvest crops 🌱💧📦
- Day/night cycle ☀️🌙  
- Mobile & keyboard controls 📱⌨️
- Only 20KB single HTML file!

## Controls
- **Desktop**: Arrow keys/WASD navigate | Enter/Space = Plant | W/1 = Water | E/2 = Harvest
- **Mobile**: D-pad buttons appear automatically
