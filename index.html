☝️ Sekali saja — sambungkan ke GitHub

App ini tidak menyimpan apa pun di server. Semua data (token, catatan job) disimpan di HP kamu sendiri. Mesin yang bekerja adalah PC Windows gratis milik GitHub.

Cara bikin token (30 detik, di HP)
  1. Buka github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → pilih anime-extract
  3. Permissions → Repository: Contents: Read and write · Actions: Read and write
  4. Expiration: pilih 90 hari (jangan “No expiration”)
  5. Klik Generate token → copy → tempel di kolom atas

Token ini cuma bisa menyentuh repo yang kamu pilih, jadi risikonya kecil. Kalau pernah menempelkan token di tempat lain (chat, catatan), sebaiknya revoke dan bikin baru.

Alurnya cuma 4 langkah

  1. Kirim — pilih file bundle dari HP → diupload ke Releases repo kamu (maks 2 GB/file)
  2. Ekstrak — pilih game + jenis asset → tekan tombol → runner Windows GitHub yang kerja
  3. Proses — pantau progress & log (bisa ditinggal, HP boleh dikunci)
  4. Hasil — unduh zip hasil langsung dari app (atau dari GitHub)

1️⃣ Kirim bundle ke GitHub

File naik ke repo private kamu sendiri (folder inbox/) — lewat jalur yang didukung browser HP, jadi tidak perlu PC. Hasil ekstraksinya tetap private.

Taruh file di sini atau
.zip · .7z · .rar · .ab · .bin — yang dipakai ekstraksi = file pertama
Lewat app ini paling aman sampai ± 45 MB. File lebih besar? Pakai kartu di bawah — tetap bisa dari HP.

File besar (> 45 MB) — lewat Releases

Releases menerima sampai 2 GB per file, tapi file-nya dilampirkan dari halaman web GitHub (3 ketukan di HP, bukan dari app):

  1. Tekan tombol di bawah → halaman release baru terbuka di browser.
  2. Attach file bundle → tekan Publish release.
  3. Tekan lama nama filenya → Copy link → tempel di kotak “pakai bundle yang sudah ada”.

Pakai bundle yang sudah ada

Kalau bundle-nya sudah ada di repo, di Release, atau di internet — tempel link atau path-nya di sini. Otomatis terisi juga di tab Ekstrak.

Bersihkan inbox repo

File di inbox/ ikut terunduh oleh runner tiap kali ekstraksi (bikin lambat + makan kuota). Hapus kalau sudah tidak dipakai.

Tekan “Muat daftar” untuk melihat isi inbox.

4️⃣ Hasil

Kenapa butuh GitHub?

AnimeStudio hanya bisa jalan di Windows, dan HP Android tidak bisa menjalankannya. GitHub menyediakan PC Windows gratis (runner windows-latest) — app ini cuma “remote control” yang mengirim perintah ke PC itu dan mengambil hasilnya. Jadi: tanpa PC, tanpa install apa pun, gratis (kuota ±1.000 menit Windows/bulan di plan Free).

Kirim bundle: 2 jalur

  • Jalur app (sampai ± 45 MB) — file diunggah ke folder inbox/ di repo private kamu lewat API GitHub. Ini jalur yang paling gampang dari HP dan sudah diuji di app ini.
  • Jalur Releases (sampai 2 GB) — untuk file besar: tombol di tab Kirim membuka halaman release baru, kamu attach file-nya dari browser HP, lalu tempel link-nya di kotak “pakai bundle yang sudah ada”.
  • Setelah ekstraksi selesai, hapus file di inbox/ (kartu “Bersihkan inbox repo”) supaya tiap run tidak mengunduh file besar lagi — dan kuota repo tetap lega.

Tips hemat & aman

  • Mulai dari bundle kecil + jenis asset Texture2D dulu, untuk memastikan kode game-nya benar.
  • Salah pilih game = hasil 0 file atau sampah. Coba entri lain (mis. GI vs GI_CB3).
  • Hasil > 450 MB otomatis di taruh di Releases (biar tidak kena kuota artifact 500 MB). Hasil > 1,8 GB dipecah otomatis.
  • App ini menyimpan token di HP (localStorage). Kalau HP dipakai bersama, tekan Hapus data setelah selesai.
  • Hasil ekstraksi tetap milik publisher game — pakai untuk keperluan sendiri, jangan disebar/dijual.
